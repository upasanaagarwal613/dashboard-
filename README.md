# Voyx – Sales Analytics Dashboard

Voyx is an interactive **Sales Analytics Dashboard** designed to transform raw sales data into clear, meaningful, and actionable business insights. The project provides a centralized interface where users can monitor sales performance, analyze orders and revenue, and identify important trends through interactive visualizations.

## 📌 Project Overview

The dashboard connects with **Supabase** to fetch and manage sales data and presents the information through an intuitive and user-friendly interface. Instead of analyzing raw datasets manually, users can quickly understand business performance using KPI cards, charts, tables, and category-wise analysis.

## ✨ Key Features

* 📊 **Interactive Sales Dashboard** – Visual representation of important sales metrics.
* 💰 **Revenue Analysis** – Track overall revenue and understand revenue trends.
* 🛒 **Order Analysis** – Monitor order volume and sales activity.
* 👥 **Customer Insights** – Analyze customer-related sales information.
* 📦 **Product Analysis** – Identify top-performing products and products with lower performance.
* 📈 **Sales Trends** – Understand changes in sales over different time periods.
* 🗂️ **Category-wise Analysis** – Compare performance across different product categories.
* 🔄 **Supabase Integration** – Fetch sales data dynamically from the database.
* 🎨 **Responsive UI** – Designed for easy viewing and navigation across different screen sizes.

## 🛠️ Technologies Used

* **HTML5** – Structure of the dashboard
* **CSS3** – Styling and responsive design
* **JavaScript** – Dashboard logic and dynamic data handling
* **Supabase** – Database and backend data management
* **Charts & Visualizations** – Graphical representation of sales data

## ⚙️ How It Works

1. Sales data is stored in **Supabase**.
2. The application connects to Supabase through JavaScript.
3. Required sales records are fetched from the database.
4. The data is processed and converted into meaningful metrics.
5. KPIs, charts, and tables are updated dynamically.
6. Users can analyze overall sales performance from the dashboard.

## 🎯 Objective

The primary objective of Voyx is to make **sales data analysis simpler and more accessible** by converting complex raw data into an understandable visual dashboard. It can help businesses and users make faster, data-driven decisions by highlighting important sales patterns and performance indicators.
